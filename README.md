# 智固 App

智固 App 是一个面向比赛演示场景的 Android 应用，用于展示“货车紧固辅助与检测”方案。  
当前版本重点突出 3 个方向：

- 货车紧固作业流程展示
- 无人机辅助牵引与图传展示
- 类似智能驾驶感知大屏的“辅助”演示页面

本项目以“演示效果优先、稳定展示优先”为目标，不以生产落地为第一目标。

## 项目特点

- 单 Activity + Jetpack Compose 构建
- 本地演示闭环完整，可离线展示
- 支持 `demo` / `dji` 双变体
- 支持演示视频替代实时图传
- 支持 DJI 接入能力保留
- 内置“辅助感知大屏”页面，适合比赛答辩展示

## 当前功能模块

### 1. 登录

- 本地登录
- 一键演示入口

### 2. 首页

- 演示总览头图
- 任务进度指标卡
- 图传 / 演示视频区
- 现场状态摘要
- 多视角状态
- 演示时间线
- 最近记录摘要

### 3. 辅助

辅助页是当前版本的重点展示模块，模拟类似智能驾驶感知大屏的效果。

支持：

- `俯视 / 侧视` 切换
- `白天 / 夜间` 主题切换
- `正常 / 风险逼近 / 安全通过` 模式切换
- 自动轮播演示
- 风险等级色带
- 目标距离提示
- 无人机、货车、人员、障碍物、尾部余量、辅助设备等动态态势图

### 4. 作业

- 作业参数录入
- 路径模板选择
- 起飞前检查
- 路径节点展示
- 路线预览
- 任务阶段推进

### 5. 检测

- 检测模式切换
- 风险项列表
- 整改闭环摘要
- 证据留痕
- 报告生成
- 演示记录生成

### 6. 设置

- 图传源切换
- 演示视频选择 / 清除
- DJI 初始化入口
- 设备状态展示
- 权限状态展示
- 当前参数汇总

## 技术栈

- Kotlin
- Jetpack Compose
- Material 3
- AndroidX Navigation Compose
- StateFlow
- Media3 ExoPlayer
- DJI Mobile SDK V5

## 构建信息

- `compileSdk = 36`
- `targetSdk = 36`
- `minSdk = 24`
- Java 11

项目包含两个 flavor：

- `demo`
  - 包名：`com.zhiguapp.demo`
  - 适合模拟器、普通安卓设备、比赛演示
- `dji`
  - 包名：`com.zhiguapp`
  - 适合 Android 真机 + DJI 设备联调

## 运行方式

### 方式一：直接安装 APK

项目根目录 `package/` 下已提供安装包：

- `智固-比赛演示版-demo.apk`
- `智固-真机联调版-dji.apk`

推荐：

- 比赛演示优先安装 `智固-比赛演示版-demo.apk`
- 真机联调 DJI 时再安装 `智固-真机联调版-dji.apk`

### 方式二：Android Studio 运行

1. 使用 Android Studio 打开项目根目录
2. 等待 Gradle 同步完成
3. 选择变体：
   - `demoDebug`
   - `djiDebug`
4. 运行到模拟器或真机

### 命令行构建

构建 demo 版：

```bash
./gradlew assembleDemoDebug
```

构建 dji 版：

```bash
./gradlew assembleDjiDebug
```

Windows 下可使用：

```powershell
.\gradlew.bat assembleDemoDebug
.\gradlew.bat assembleDjiDebug
```

## DJI 说明

项目已保留 DJI 接入能力，但为了避免普通 Android 设备启动闪退，当前策略是：

- `dji` 版不在启动时自动初始化 DJI SDK
- 改为在“设置”页手动初始化
- 初始化失败时显示错误状态，不直接导致应用崩溃

这使得项目同时兼顾：

- 比赛演示稳定性
- DJI 技术亮点展示

## 辅助页说明

辅助页是当前版本最适合比赛展示的界面。

建议演示方式：

1. 先展示 `俯视`
2. 切换到 `侧视`
3. 切换 `白天 / 夜间`
4. 切换 `正常 / 风险逼近 / 安全通过`
5. 最后点击 `自动演示`

这样可以在较短时间内向评委展示页面层次、动态效果和演示逻辑。

## 项目定位说明

这个项目当前更接近“比赛展示原型”，而不是生产级系统。

当前未覆盖的内容包括：

- 后端服务
- 数据持久化
- 真实账户体系
- 真实算法识别
- 飞控任务调度闭环
- 商业化上架能力

但从比赛演示角度看，当前版本已经具备：

- 可运行
- 可安装
- 可切换
- 可讲解
- 可演示亮点
